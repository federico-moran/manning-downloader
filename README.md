# Manning Downloader

Downloads the ebooks you own on [Manning](https://www.manning.com/dashboard), with your own logged-in session. A sibling of [humblebundle-downloader](https://github.com/federico-moran/humblebundle-downloader) and [packtpub-downloader](https://github.com/federico-moran/packtpub-downloader).

Work in progress.
